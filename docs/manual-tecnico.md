# Manual Técnico

## 1. Descripción técnica
El proyecto es una aplicación sencilla que se ejecuta desde la consola. Recibe datos por teclado, realiza un cálculo y muestra el resultado en pantalla.

## 2. Tecnología utilizada
- Python.

## 3. Requisitos
- Python instalado.
- Editor de código o terminal.

## 4. Estructura del proyecto
- README.md: presentación general del proyecto.
- calculadora_promedio.py: programa principal.
- docs: carpeta de documentación.
- docs/manual-usuario.md: instrucciones para el usuario.
- docs/manual-tecnico.md: información técnica.
- docs/img: imágenes de evidencia.

## 5. Preparación
1. Guardar todos los archivos dentro de la carpeta del proyecto.
2. Verificar que Python esté instalado.
3. Abrir la carpeta en Visual Studio Code.

## 6. Ejecución
Abrir la terminal en la carpeta del proyecto y ejecutar calculadora_promedio.py con Python.

## 7. Funcionamiento
El programa solicita el nombre del estudiante y tres notas mediante el teclado. Convierte las notas a números, calcula el promedio sumándolas y dividiendo entre 3, y muestra el resultado redondeado a dos decimales. Si el promedio es 51 o más, muestra Aprobado; en caso contrario, muestra Reprobado.

## Descripción
Proyecto sencillo de consola que calcula el promedio de tres notas de un estudiante y muestra si está aprobado o reprobado.

## Objetivo
Practicar la documentación de un proyecto utilizando Markdown.

## Funciones principales
- Solicitar el nombre del estudiante.
- Solicitar tres notas.
- Calcular el promedio de las notas.
- Mostrar el promedio y el estado (Aprobado o Reprobado).

## Requisitos
- Python instalado.
- Visual Studio Code o una terminal.

## Ejecución

### Windows

```powershell
python calculadora_promedio.py
```

### Linux

```bash
python3 calculadora_promedio.py
```
